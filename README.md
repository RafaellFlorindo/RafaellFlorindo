<details>
<summary><b>Five rules I build by</b></summary>
<br>

1. **Production over demos.** Retries, partial data, API failures and human handoff are design inputs, not edge cases.
2. **Explicit business logic.** Tools change; the operational contract shouldn't disappear inside platform clicks.
3. **Reusable delivery.** Recurring work becomes snapshots, schemas, templates, agents and tested workflows.
4. **Cost and security are architecture.** Tenant isolation, API budgets and privacy are product constraints.
5. **Proof over badges.** Tests, deployments and decisions weigh more than a list of logos.

</details>
